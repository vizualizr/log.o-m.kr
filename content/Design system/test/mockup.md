## Summary

- 배색, 폰트를 미리 검증할 수 있는 도구를 만든다.
- 웹페이지에 바로 레이어로 떠 있는 형태여야 한다.

## Steps

### 구현을 위한 프롬프트

현재 페이지에 새로운 UI 요소를 추가할 거야. 다음 스펙을 검토해서 바닐라js구현 가능한지 판단해.

- 최상단에 고정 바를 추가한다.
- 해당 바에서 사용자는 임의의 폴더를 추가할 수 있다.
- 해당 폴더에는 TTF, OFT 등의 폰트 파일이 있다고 가정한다
- 사용자가 폴더를 선택하면 웹페이지는 이 폴더에서 폰트 목록을 생성해 드랍다운 메뉴를 생성한다.
- 사용자가 드랍다운메뉴에서 특정 폰트를 생성하면 해당 페이지의 기본 폰트를 해당 폰트로 수정한다.
- 이 페이지의 기본 폰트는 현재 base.css에 있는 --font-sans에서 지정한다.

지원 브라우저는 우선 chrome만 고려한다. 설계한 스펙에 따라 기능을 구현하라. 아래 단위로 쪼개 각 단계마다 내가 실제 테스트한 뒤 해당 기능이 구현하면 다름 기능을 구현해서 결합하는 방식으로 진행하는 게 가능한지 우선 점검하라.

- UI 추가해 폴더 선택해 해당 폴더에 접근 권한이 있는지 확인
- 접근 권한을 확인한 폴더에서 폰트 파일만 선별해 목록을 작성하는 게 가능한 지 확인
- 위에서 작성한 목록에서 첫번째 폰트를 선택해 해당 폰트 정보를 css에 추가하는 게 가능한지 확인
- css에 추가한 폰트 정보로 index.html 페이지의 기본 폰트로 설정 가능한지 확인.
- 위 사항을 확인하면 폰트 목록을 드랍다운 목록으로 생성하는 기능을 확인
- 드랍다운으로 폰트 목록 생성을 확인하면 해당 목록에서 선택한 폰트를 index.html 페이지 기본 폰트로 지정할 수 있는지 확인.
