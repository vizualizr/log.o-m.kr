## Summary

프리텐다드 GOV, IBM Plex Sans KR 등이 가장 이상적이다.

정방형보다 가로가 약간 좁은 형태여야 글에 집중할 수 있다. 어차피 긴 글을 쓰는 곳이 아니므로 글꼴의 피로도보다 주목도가 더 중요하다.

다만 컬럼 등에 쓰이는 글꼴의 장평이 너무 좁으면 분명 글을 읽을 때 피로도가 커질 수 있으니 아래에서 보완법을 확인하라.

## Troubleshooting

- 프리텐다드, IBM Plex Sans KR 등으로 긴 글을 읽을 때 피로도가 걱정된다면 다음과 같이 조정하라.

  - 기본적으로 두 글꼴은 가독성에 초점을 둔 폰트이다. 또한 장평 조절을 위한 글자너비 축(`wdth`)를 지원하지 않는다. 단 글자 굵기 축(`wght`)만 지원한다.
  - 따라서 장평을 조정하기 보다는 줄간격과 자간으로 가독성을 올리는 편이 더 낫다.
  - 단 아래 적용 후 반드시 테스트를 거쳐 확정하라.

  ```css
  /* 줄간격 넉넉히 주기:** 본문 폰트 크기의 1.6~1.75배로 설정 */
  line-height: 1.65;

  /* **미세한 자간 줄임:** 한글 웹폰트는 자간을 아주 살짝 줄여주면 눈이 글자 뭉치를 더 쉽게 인지합니다. */
  letter-spacing: -0.01em; /* 또는 -0.02em */
  ```
