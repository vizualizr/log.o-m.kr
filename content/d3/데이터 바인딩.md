## Summary

-
- 데이터 바인딩이란 주어진 데이터와 이를 표현하는 요소 사이의 1:1 대응 관계를 확정하는 작업이다. 웸 문서에서 데이터 바인딩을 마치면 주어진 데이터의 모든 원소는 반드시 HTML 문서의 DOM 요소와 1:1 대응 관계를 가지게 된다.이를 위해 문서를 구성하는 요소 가운데 일부를 추가, 삭제할 수 있으며 필요할 경우 내부 상태를 갱신할 수 있다.
- d3.js는 이 과정을 두 단계로 나눈다. 우선 주어진 데이터와 현재 선택된 DOM 요소를 바탕으로 `selection.data(data, key)`이 1:1 대응 관계를 확정해 `d3.selection` 객체로 반환한다. `selection.join(enter, update, exit)`은 반환된 객체에 기록된 데이터와 DOM 요소의 대응관계를 실제 DOM 요소에 적용한다. 이를 위해 `join()`은 필요에 따라 DOM 요소를 추가, 삭제, 갱신한다.

## Steps

- d3.js에서 `data()`는 주어진 데이터의 목록을 바탕으로 1:1 대응에 필요한 출력 요소의 목록을 결정하는 역할을 한다. 기술적으로 이 과정은 데이터 길에 따라 필요한 출력 요소 개수를 확정한 뒤 각 출력 요소에 부합하는 데이터를 확정하는 과정이다. 목록과 데이터를 확정하면 출력 요소를 제어하는 단계로 넘어갈 준비가 끝난 상태가 된다.
- `join()`은 목록에 따라 출력 요소의 목록을 기준으로 출력 요소를 갱신, 추가, 삭제하는 역할을 담당한다.
- d3.js의 데이터 바인딩은 일회적이며 단방향이다. 즉 데이터가 갱신될 때마다 새로운 목록을 작성하며 출력 요소의 변화를 데이터에 반영하는 경우는 없다.

### [[d3/modules/d3-selection/selectAll(selector)|selectAll(selector)]]

> [!NOTE] 우선 데이터 바인딩이 d3.selection 객체에 저장된 DOM 요소들과 구조를 알아야 한다.
> 그래야만 어디에 무슨 DOM 요소를 추가, 삭제, 수정할지 알 수 있다. 때문에 `.selectAll()`이 반환한 Selection의 각 DOM 요소를 부모로 삼아 그룹 배열을 하나씩 만든다.

### [[d3/modules/d3-selection/selection.data(data, key)|selection.data(data, key)]]

Journal/2026-09-03|2026-09-03`data(data, key)`는 `data`을 기준으로 [[d3/modules/d3-selection/d3.Selection|d3.Selection]]에 등록된 DOM 목록과 해당 DOM에 할당된 값을 갱신한다. 정확한 순서는 아래와 같다.

1. 우선 `d3.selection`에 기록된 기존 DOM 요소의 목록을 순회한다.
   1. `key`로 입력 받은 키 함수(혹은 값)에 따라 ==기존 DOM 요소의 색인(key) 목록==을 만든다. 색인이므로 각 색인은 고유하며 각 DOM 요소와 1:1 대응하는 것이 원칙이다. 이를 **기존 DOM 색인**이라 한다.
   2. 기존 DOM 색인은 d3.js 내부의 임시 해시 맵(hash map)에 임시 등록하며 `data()`가 처리를 완료하면 삭제한다.
   3. key 함수에 따라 색인을 추출하는 과정에서 복수의 DOM 요소가 동일한 색인을 요청하는 경우가 발생할 할 수 있다. 이 경우 해당 색인을 선점한 첫 번째 DOM외의 다른 원소는 삭제하기 위해 `exit()` 대상 목록에 추가한다.
2. 색인 생성을 마쳤으므로 새로 입력된 `data`을 순회한다.
   1. 앞의 단계와 마찬가지로 우선 ==\`key\`로 입력 받은 함수(혹은 값)에 따라 새로 입력된 \`ㅇdata\` 요소의 색인(key) 목록==을 만든다. 이를 **data 색인**이라고 하자.
   2. 1 단계에서 작성한 기존 **DOM 색인**과 **data 색인**을 1:1로 조회하는 단계를 시작한다.
   3. data 색인 가운데 DOM 색인과 일치하는 원소를 발견하면 해당 data 원소를 DOM 원소의 `__data__`에 주입하고 해당 원소를 `update()` 대상 목록에 추가한다.
   4. DOM 색인에서 일치하는 원소를 찾지 못한 data 색인 원소는 해당 원소를 생성해야 하므로 `enter()` 대상 목록에 추가한다.

### [[d3/modules/d3-selection/selection.join(enter, update, exit)|selection.join(enter, update, exit)]]

`selection.data(data, key)`에서 확정된 DOM 목록에 따라 문서에서 DOM을 추가, 갱신, 삭제한다.
